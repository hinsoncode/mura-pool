# Mura pool

Public assets for the Mura stake pools (MURA1 to MURA7).

## Logo

| File | What it is |
| --- | --- |
| `logo/mura-logo-original.jpeg` | the source image, 1254 × 1254 JPEG, as received 2026-09-25 |
| `logo/mura-logo.png` | 1024 × 1024 PNG, made from the source; meets the laksa console's logo rules (PNG, square, 128 to 1024 px, at most 1 MB) |
| `logo/mura-logo-64.png` | 64 × 64 PNG icon, made from the source |

The pools' metadata does not link to these files. Explorers read the logo from
`https://kes-tool.vercel.app/pool/mura-logo.png` and `/pool/mura-logo-64.png`, which serve
whatever was last published from the console's Logo tab.
